# ML Assignment 3 — Data Preprocessing

Dataset: UCI Census Income / Adult  
Source: https://archive.ics.uci.edu/dataset/20/census+income

The notebook demonstrates:
- stratified train/test split before fitting transformations
- three missing-value strategies
- three outlier approaches
- one-hot, ordinal and frequency encoding
- unseen-category handling
- scaling and skewness transforms
- leakage demonstration
- SMOTE on training data only
- persisted preprocessing pipeline

`pipeline.joblib` is generated after running Q11.
